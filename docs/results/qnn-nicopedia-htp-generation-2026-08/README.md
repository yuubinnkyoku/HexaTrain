# Nicopedia byte-level HTP generation, August 2026

This milestone loads the HTP-trained Nicopedia checkpoint into a QNN HTP
graph and runs byte-level generation. The generation forward's numerical
operations execute on HTP; CPU performs prompt encoding, the 32-byte rolling
context window, sampling, and host control. QNN automatic differentiation is
not used, and no NPU-only inference claim is made.

## Protocol

- Byte vocabulary (V=256, no EOS); context is always a rolling 32-byte
  window.  Shorter prompts are NUL-padded at the front; longer prompts use
  the last 32 bytes (training-window semantics).
- Generation stops only at MaxNewBytes (1..1024).
- Every run is gated: 4 fixed-prefix CPU/HTP parity rows (logits max abs
  error < 2e-2, probabilities < 5e-3) and an 8-step autoregressive parity run
  (same tolerance; divergence is blocked when the CPU top-1/top-2 margin at
  the decision point exceeds 0.01).
- Display is lossless: invalid or truncated bytes are \xNN-escaped, never
  dropped.

## Results

- Aggregate only: byte counts, UTF-8 validity stats, parity/AR error
  magnitudes, gate booleans, timing, and thermal records.
- Prompt text, generated bytes, article sets, token rows, checkpoints,
  serials, and all content fingerprints are private and excluded from this
  bundle by the allow-list exporter.
