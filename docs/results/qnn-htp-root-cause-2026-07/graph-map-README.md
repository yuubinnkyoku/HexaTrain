# Tiny LM QNN logical graph map

`node-map.csv` and `tensor-map.csv` are a source-layout map of the fixed-state
TinyTransformer language-model graph (`B1_T8_V32_D16`, one layer/head, FFN 32,
FP32). They are generated by `scripts/export_qnn_tiny_lm_graph_map.ps1`.

The exporter parses `TinyTransformerTrainingGraph::TensorIndex`, checks the
`make`, `many`, LayerNorm-forward, and LayerNorm-backward graph builder
markers, and refuses to export unless it accounts for exactly 153 source
tensors and 123 FULL-variant source nodes. `creation_index` is zero-based
source creation order. This is a logical source map, not a dump of opaque QNN
handles or a claim about backend-lowered node order.

For each node, the CSV records its QNN operation, logical tensor inputs and
output, output shape/type, exposure, and variant membership. For each tensor,
it records its source creation index, producer/consumers, role, shape/type,
memory and I/O classification, exposure, and variant membership. The exposure
column describes the headless fixed-state configuration with diagnostic outputs
enabled. Conditional entries state the source condition explicitly, including
the graph-preserving `BACKWARD_REGIONS` and `LAYERNORM1` tap sets.

`FULL`, `STOP_AFTER_DINPUT`, and `STOP_AFTER_DEMBEDDING` refer to the existing
runtime variants. The map deliberately contains no pointer, device identifier,
endpoint, absolute path, checkpoint contents, or raw tensor value.
