# Taste: コミュニケーションと報告

- ユーザーは日本語で質問・指示する。説明・概要報告・通常の会話はすべて自然な日本語で行う（内部のsubagent prompt等は英語でもよい）。Confidence: 0.8

- 最終報告は英語の大文字分類名（FINAL_STATUS、RESULT_CLASSIFICATION等の列挙）を本文に大量に並べず、普通の自然な日本語で簡潔に報告することを強く好む。Confidence: 0.95
- 最終報告は「最終状態（完了 / 一部完了 / 中断）/ 結論 / 開始HEAD / 最終HEAD / 端末・runtime identity / データ・config / 主要gate結果 / commit数 / push済み / 停止理由」のような固定テンプレートの見出し群から始め、続けて実施工程を実行順（監査→実装→検証→公開→Reviewer→push→CI）に簡潔にまとめる形式を好む。Confidence: 0.95
- 結論は証拠の強さ（観察 / 機構候補 / 因果支持 / 主要因 / 根本原因）と対応させ、証拠以上に強い主張をしない。残る不確実性を明記することを好む。Confidence: 0.9
- 否定結果や「判定不能」でも、科学的に十分な停止条件を満たせば完了として報告してよい（無理に肯定・否定へ分類しない）。Confidence: 0.85
- 実施していない分析・工程をPASS扱いせず、NOT_RUN / GATE_REJECTED 等として明示的に区別することを好む。Confidence: 0.85
- 否定結果・「改善不能」の結論でも、候補ごとの改善量・残存誤差・原因の限界を定量化して報告する（「無理に通さない」）。Confidence: 0.8
